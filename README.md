## Topic Overview

Relevant documents do not always provide a complete answer when the evidence depends on relationships spread across multiple sources. Graph-based approaches make these relationships explicit, helping RAG systems retrieve connected evidence.

This project examines how knowledge graphs organize evidence, how graph structure informs retrieval and prompting, and how workflow graphs coordinate retrieval, evaluation, and generation. It also discusses the tradeoffs of graph construction, accuracy, and maintenance.
